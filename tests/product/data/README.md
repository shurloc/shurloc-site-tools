# Data

## Supported variation formats

- 110/80 Yellow $23.75
- 110/71 (S) White $24.50
- 230/40 Thin Thread Yellow $32.21
- 5 Pack - 110/80 Yellow ($98.55)

## Normalization

- Whitespace is normalized.
- "Thin Thread" is normalized to modifier S.
- Modifiers are case-insensitive.
- Colors are case-insensitive.
- Prices may be parenthesized.
